Wordfall 개인정보 처리방침

시행일: 2026년 10월 22일

Wordfall은 Chrome Web Store에서 제공되는 픽셀 타이핑 디펜스 게임입니다. 본 방침은 Wordfall Chrome 확장 프로그램과 관련 웹 페이지에서 처리하는 정보의 종류, 이용 목적, 보관 및 이용자 권리를 설명합니다.

1. 수집·처리하는 정보

  • 게스트 로그인: Firebase Authentication이 발급하는 익명 사용자 ID.
  • Google 로그인: Firebase Authentication 계정 ID와 Google 계정의 기본 프로필 정보(표시 이름 및 이메일 주소 등). 로그인과 계정별 게임 데이터 구분에 필요한 범위에서만 사용합니다.
  • 게임 및 프로필 정보: 닉네임, 선택 캐릭터, 코인, 닉네임 변경권, 점수·게임 통계, 언어 및 게임 설정.
  • 닉네임 중복 확인 정보: 닉네임, Firebase 사용자 ID, 갱신 시각. 닉네임 중복 방지와 계정 소유권 확인을 위해 Firebase Firestore에 저장될 수 있습니다.
  • 기술 정보: 로그인·서비스 오류 확인에 필요한 Firebase 인증 및 보안 관련 기록. Wordfall은 게임 기능과 무관한 웹사이트 방문 기록, 검색 기록, 요청한 URL 또는 페이지 내용을 수집하지 않습니다.

2. 이용 목적

  • 게스트 및 Google 로그인 제공
  • 계정별 프로필, 닉네임, 캐릭터, 점수 및 게임 진행 데이터 분리·저장
  • 닉네임 중복 방지와 랭킹·게임 기능 제공
  • 상점, 코인, 캐릭터 보유 상태 및 게임 설정 제공
  • 공지사항, 업데이트 안내 및 서비스 오류 대응
  • 부정 이용 방지와 서비스 보안 유지

3. Google API 및 Limited Use

Google 로그인으로 받은 정보는 Wordfall의 로그인, 계정 식별, 계정별 게임 기능 및 이용자 요청에 따른 서비스 제공에만 사용합니다.

Google API에서 받은 정보는 광고 타기팅, 이용자 프로파일링, 신용·대출 심사, 판매 또는 데이터 브로커 업무에 사용하지 않습니다. 해당 정보는 필요한 서비스 제공을 위해서만 처리하며, 판매하거나 관련 없는 제3자에게 이전하지 않습니다.

Google API에서 받은 정보의 사용은 Chrome Web Store 사용자 데이터 정책 및 Limited Use 요구사항을 준수합니다.

4. 제3자 서비스 및 공유

Wordfall은 다음의 외부 서비스를 사용합니다.

  • Google Firebase Authentication: 게스트 및 Google 로그인
  • Google Firebase Firestore: 닉네임 중복 확인 및 서비스 데이터 처리
  • Firebase Hosting: Google 로그인 보조 페이지 및 개인정보 처리방침 제공

이용자 정보는 위 기능을 제공하는 데 필요한 범위에서만 해당 서비스에 전달됩니다. Wordfall은 개인정보를 판매하지 않으며 맞춤형 광고를 제공하지 않습니다. Firebase의 개인정보 및 데이터 처리에 관한 내용은 Firebase 개인정보 안내에서 확인할 수 있습니다.

5. 보관 기간 및 삭제

브라우저에 저장되는 게임 데이터는 이용자가 브라우저 데이터 또는 확장 프로그램 데이터를 삭제하거나 계정 삭제를 요청할 때까지 보관될 수 있습니다. Firebase 인증 정보와 Firestore의 계정 연결 정보는 서비스 제공에 필요한 기간 동안 보관되며, 계정 삭제 요청 또는 관련 법령에 따라 삭제·처리됩니다.

이용자는 Wordfall의 회원 탈퇴 기능을 이용하거나 아래 연락처로 삭제를 요청할 수 있습니다. 닉네임 중복 방지를 위해 보관된 닉네임 정보도 삭제 요청 범위에 포함됩니다.

6. 보안

서비스와 Firebase 간 통신은 HTTPS 등 보안 통신을 사용합니다. Firebase의 보안 규칙과 인증 기능을 이용해 계정별 데이터 접근을 제한합니다. 다만 인터넷 전송 및 전자 저장 방식이 완전히 안전하다고 보장할 수는 없습니다.

7. 이용자의 권리

Wordfall Privacy Policy

Effective date: October 22, 2026

Wordfall is a pixel typing defense game distributed through the Chrome Web Store. This policy explains the information handled by the Wordfall Chrome extension and related web pages.

1. Information We Handle

  • Guest sign-in: The anonymous user ID issued by Firebase Authentication.
  • Google sign-in: The Firebase Authentication account ID and basic Google profile information, such as display name and email address, used for sign-in and account-specific game data.
  • Game and profile information: Nickname, selected character, coins, nickname-change tickets, scores, game statistics, language, and settings.
  • Nickname reservation information: Nickname, Firebase user ID, and update time, used to prevent duplicate nicknames and verify ownership.
  • Technical information: Firebase authentication, security, and error records needed to operate and protect the service. Wordfall does not collect browsing history, search history, requested URLs, or unrelated website content.

2. How We Use Information

  • Provide guest and Google sign-in
  • Separate and store account-specific profiles, nicknames, characters, scores, and game progress
  • Prevent duplicate nicknames and provide ranking and gameplay features
  • Provide the shop, coins, owned characters, and settings
  • Provide announcements, update notices, and error support
  • Prevent abuse and maintain service security

3. Google API Limited Use Disclosure

Information received through Google sign-in is used only for authentication, account identification, account-specific game features, and services requested by the user.

Google API information is not used for targeted advertising, profiling, credit or lending decisions, sale, or data-broker activities. It is not sold or transferred to unrelated third parties.

Our use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including all Limited Use requirements.

4. Third-Party Services

Wordfall uses Firebase Authentication, Firebase Firestore, and Firebase Hosting. Information is shared with these services only as necessary to provide authentication, nickname validation, game services, and the related web pages. Wordfall does not sell personal information or provide targeted advertising.

See Firebase Privacy and Security for Firebase privacy information.

5. Retention and Deletion

Browser-stored game data may remain until the user deletes browser or extension data or requests account deletion. Firebase account and Firestore information may be retained as needed to provide the service and will be deleted or handled according to a deletion request and applicable law.

6. Security

Wordfall uses HTTPS for service communication and Firebase authentication and security rules to restrict account-related access. No method of internet transmission or electronic storage is completely secure.

7. User Rights and Contact

Users may request access, correction, deletion, or restriction of processing. Please contact j8648638j@gmail.com for privacy questions or deletion requests.

8. Changes

We may update this policy when the service, law, or third-party services change. The effective date will be updated and changes will be posted on this page.
